# SignHire — Evaluation Caveat

All results in this directory are based on a **small, self-recorded dataset**:

- Approximately 480 clips total (8 signs × ~20 clips × 3 signers)
- All signers recorded in the same environment on the same machine
- Leave-one-signer-out cross-validation with 3 folds

**These results should be treated as indicative only.**

They reflect within-dataset performance under controlled conditions.  
Generalisation to other signers, different lighting, varied camera distances,  
or different signing styles has **not** been tested and cannot be claimed.

Every metric in this folder was computed by the evaluation scripts in  
`src/evaluate/evaluate.py`.  No number has been hardcoded or estimated.  
If a model has not yet been trained, the scripts will say so explicitly.
